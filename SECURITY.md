# Security policy

安全策略 / Security policy

## 支持范围

安全修复针对本仓库 `main` 分支的最新源码。使用者自行部署后的主机、域名、数据库和第三方账户配置由部署者负责。

## 私下报告

请通过 [GitHub Security Advisories](https://github.com/Kohaku233/open-alert/security/advisories/new) 私下报告可被利用的漏洞。不要创建公开 Issue 或 Pull Request。报告应说明影响范围、复现条件和概念性验证方法，不要包含可用密钥、会话、生产数据或攻击载荷。

维护者会尽力在 7 天内确认收到报告，并在修复可用后协调公开说明。本项目目前没有奖金计划。

## Supported versions

Security fixes apply to the latest source on the `main` branch. Operators are responsible for the hosts, domains, databases, and third-party accounts in their own deployments.

## Private reporting

Report exploitable vulnerabilities through [GitHub Security Advisories](https://github.com/Kohaku233/open-alert/security/advisories/new). Do not open a public issue or pull request. Describe the impact, reproduction conditions, and a conceptual verification method. Do not include usable secrets, sessions, production data, or attack payloads.

Maintainers will try to acknowledge a report within 7 days and coordinate disclosure after a fix is available. This project currently has no bug-bounty program.
