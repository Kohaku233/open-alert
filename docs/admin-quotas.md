# 管理员业务额度

管理员由服务端数据库中 `user.role='admin'` 决定，客户端不能通过套餐名称、请求参数或请求体申请豁免。

管理员不受以下业务额度限制：

- 价格规则总数、规则使用的市场数量以及普通用户共享的规则/市场容量。
- 账户、全站和各通知路由的每日发送额度。现有路由中保存的 5、10 等数字不会拦截管理员。
- 通知渠道数量与收藏数量。

API 使用 `null` 表示无限额度，设置和仪表盘显示“无限”；不会用极大的整数伪装无限。通知中心另外返回 `unlimited`，管理员的路由日额度显示为只读无限。有限的旧配置继续保留，以支持普通用户规则和日后角色变更。

每日尝试次数仍如实记录。普通用户的全站每日预算从全站统计中扣除同日管理员的使用量；普通用户的规则/市场总容量也不计管理员持有的规则/市场。

管理员仍遵守账户禁用、监控及渠道开关、免打扰、行情有效性、异动冷却、发送幂等、租约和不确定结果不重发等规则。第三方服务的配额与发送频率限制也不由本应用豁免。单次处理时间、队列大小、请求体大小等运行保护继续生效，工作量通过分页和后续调度处理。

Node 行情源不再把普通用户的全站标的业务上限作为管理员的订阅容量。普通用户的标的上限仍由数据库原子写入和调度检查执行。

本次不更改邀请注册政策或普通用户套餐，也不启用收费。
