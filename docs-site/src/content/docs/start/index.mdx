价格哨站在服务器上盯着交易所的最新成交价。价格到达你设定的位置时，系统会通过你绑定的渠道发送提醒。关掉浏览器或合上电脑，后台也照常工作。

<Steps>

1. **登录**

   访问 [cryptotool.bar](https://cryptotool.bar)，使用受邀邮箱完成登录。支持通过 Google 快捷登录或接收邮箱验证码登录，两种方式登录对应同一个账户。详情参见 [登录与邀请](/start/sign-in/)。

2. **添加通知渠道**

   前往 **通知** 页面，点击 **添加渠道**，选择 Pushover 或 Discord 并填写对应密钥或 Webhook 地址。随后在下方的 **推送规则** 中将“价格警报”指派至该渠道，并点击 **保存推送路由**。详情参见 [通知渠道](/notify/channels/)。

3. **创建第一条警报**

   返回 **行情** 页面，选定交易所与交易对，点击 **创建警报**，根据需求选择“达到或高于”或“达到或低于”，并设定目标价位。详情参见 [创建第一条警报](/start/first-alert/)。

4. **打开监控总开关**

   新注册账户的监控总开关默认处于关闭状态。在行情页手动将其开启后，后台才会正式开始行情判断。

</Steps>

<Aside type="tip" title="想先确认通知能收到">
在通知页面点击对应渠道旁的 **测试** 按钮，系统会发送一条普通优先级的测试通知。同一渠道在 30 秒内仅允许发起一次测试。
</Aside>
