title: 创建第一条警报

---

<Steps>

1. **选择标的**

   在行情页顶部搜索框输入币种代码，例如 `BTC`。搜索结果按标的统一归集，点击标的名称会默认打开首选交易所（优先 Binance）。点击右侧交易所标签可直接快速切换。

2. **确认交易所和市场类型**

   标的名称下方支持灵活切换交易所（Binance、OKX、MEXC）及市场类型（现货或 USDT 永续）。后续警报判断将严格依据此处保存的交易所和市场数据执行。

3. **创建警报**

   点 **创建警报**，填写：

   - **警报名称**：自定义易于辨识的备注名称，例如“突破前高”。
   - **触发条件**：选择“达到或高于”或“达到或低于”。
   - **价格**：设定的目标价位，数值必须大于零。

   也可以在图表相应价位上悬停或长按，点击浮现的 **+** 图标直接快速创建警报。

4. **打开监控总开关**

   新注册账户的监控总开关默认处于关闭状态。开启开关后，后台服务才会正式开始评估你名下所有处于启用状态的警报。

</Steps>

## 保存后会立刻触发吗

确实有可能。若当前交易所最新成交价已满足设定的触发条件，保存配置后接收到的第一笔新鲜行情数据就会立即触发。例如 BTC 现价为 70,000，而你设定的条件为“达到或低于 72,000”，在保存后数秒内便会收到提醒通知。

<Aside type="caution" title="图表上的画线不会提醒">
图表上的趋势线、水平线等画线仅供看图辅助，不会触发任何行情通知。若需要在关键价位获取提醒，请务必单独创建警报。
</Aside>
