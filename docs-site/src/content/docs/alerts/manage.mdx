## 警报的几种状态

| 状态 | 含义 | 你能做什么 |
| --- | --- | --- |
| 已武装 | 正在等待价格满足条件 | 编辑、暂停、删除 |
| 已排队 / 正在发送 | 已触发，通知正在投递 | 等待完成，这段时间不能修改 |
| 已触发 | 已经发过通知，处于锁定状态 | 重新武装、编辑、删除 |
| 结果不确定 | 通知可能已送达，也可能没有 | 先看手机，再决定是否重新武装 |

## 重新武装

已触发过的警报需手动点击 **重新武装** 才会再次生效。修改价格数值或开关状态均不会自动解除锁定，从而避免因调整参数而意外触发通知。

## 监控总开关

总开关控制你账户下的所有价格警报：

- **关闭**：所有警报均不会触发，待发队列中尚未送出的通知也会一并取消。已经向渠道发出的请求则无法撤回。
- **打开**：恢复行情判断。开启后，只要接收到第一个满足条件的新鲜价格便会立即触发。

<Aside>
监控总开关仅控制价格警报。异动监测配有独立的专属开关，两者互不影响。
</Aside>

## 删除警报

删除后该警报会从列表中移除，但历史投递记录仍由后台保留。正处于排队或发送流程中的警报，需待发送完成后方可删除。
