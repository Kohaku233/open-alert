行情页的内置图表直接采用所选交易所的 K 线，与警报使用的是同一家交易所的数据。你也可以切换到 TradingView 图表，但 TradingView 仅供参考，警报不会依据它来判断。

## 切换周期

图表上方可以选常用周期，也可以自定义：

- 直接输入数字表示分钟，例如 `7`、`90`。
- 加 `H`、`D`、`W` 表示小时、天、周，例如 `2H`、`3D`。
- 鼠标停在图表上时直接敲数字也能切换，回车确认，`Esc` 取消。

交易所未直接提供的周期会由系统自动合成。若少数周期在特定交易所无法生成，界面会提示更换其他周期。

## 在图上管理警报

- **创建**：悬停或长按图表，点出现的 **+**，就在那个价位创建警报。
- **改价**：按住警报线上下拖动，松开后确认新目标价。

## 画线工具

左侧工具栏有趋势线、射线、水平线、矩形、斐波那契、价格区间等工具，分组方式和 TradingView 类似。

- 常用工具可以收藏到浮动工具栏。
- 磁吸功能可让画线自动吸附到 K 线的最高、最低、开盘或收盘价，点击可在关闭、弱、强三种状态间切换。
- 画线内容保存在当前浏览器本地。更换浏览器或清理浏览器缓存数据后，画线不会同步保留。

<Aside type="caution">
画线仅用于辅助看图，不会触发任何通知。需要在特定价位提醒时，请单独创建警报。
</Aside>
