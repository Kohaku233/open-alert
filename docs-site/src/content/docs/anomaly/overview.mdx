---
title: 异动监测是什么
description: 异动监测会扫描哪些合约，和价格警报有什么区别。
---

价格警报需要用户自行指定目标价。异动监测则无需设置价位，系统会主动扫描大量合约，发现某个标的的涨跌和成交额都明显超出平时水平时提醒你。

## 和价格警报的区别

| | 价格警报 | 异动监测 |
| --- | --- | --- |
| 谁来定条件 | 你设目标价 | 系统按统计规则判断 |
| 范围 | 你选的市场 | Binance、OKX、MEXC 的 USDT 永续合约 |
| 开关 | 监控总开关 | 异动推送开关，两者独立 |
| 频率 | 每条警报触发一次 | 规则较严格，平均每天几条 |

## 监测哪些合约

- Binance、OKX、MEXC 的 USDT 永续合约。
- 24 小时成交额至少 1,000 万美元。
- 币种合约还需能在 CoinGecko 上匹配到对应代币，且流通市值不低于 1,000 万美元。
- 股票与 TradFi 合约（如美股相关合约）归为独立类别，支持单独开启或关闭。

## 开启步骤

1. 在 **通知** 页的推送规则中，将“币种异动”或“股票异动”关联至至少一个已启用的通知渠道。
2. 前往 **异动** 页，开启 **异动推送** 总开关，再按需开启 **币种合约** 与 **股票与 TradFi 合约**。

若当前没有任何渠道接收异动消息，界面会提示“暂时无法推送”，且无法开启推送开关。

<Aside type="caution" title="异动提醒不是买卖信号">
异动监测捕捉的是“已经发生的异常行情”。它主要用于提醒你及时关注盘面，无法预测后续的价格走势。
</Aside>
