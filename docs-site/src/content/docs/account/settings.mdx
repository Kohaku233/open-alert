**设置** 页集中显示你的账户信息和用量。

## 账户信息

- 邮箱和名称。
- 可用的登录方式。

## 测试资格与用量

测试期间，所有受邀并启用的账户都享有 Pro 功能，暂不收费。这里会显示你当前用了多少：

- 价格警报数量
- 监控市场数量
- 通知渠道数量
- 标的收藏数量
- 今天的价格警报投递尝试次数

点击 **刷新用量** 可获取最新数据。

## 外观与语言

- **外观主题**：跟随系统、深色或浅色。
- **界面语言**：中文或英文。

这些偏好保存在当前浏览器里。
