---
title: 额度与限制
description: 每个账户能创建多少警报、收多少条通知。
---

测试期间的额度如下。每日额度都按 UTC 零点（北京时间早上 8 点）重置。

| 项目 | 上限 |
| --- | --- |
| 价格警报 | 20 条，包含暂停的 |
| 监控市场 | 8 个 |
| 通知渠道 | 10 个 |
| 标的收藏 | 50 个 |
| 价格警报每日尝试 | 20 次，包含测试、失败和重试 |
| 每个渠道每类消息每日上限 | 1 到 50，自己设，默认 10 |

## 全站共享的限制

站点还设置了全站范围的上限，比如全站同时启用的警报数和每天的总通知数。这些上限由所有用户共享，接近上限时新建警报可能会被拒绝，并提示“已达到警报、市场或用户数量上限”。
