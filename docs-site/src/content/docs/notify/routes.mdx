推送规则决定每类消息发到哪些渠道。消息有三类：

| 消息 | 什么时候发 |
| --- | --- |
| 价格警报 | 价格到达你设的目标价 |
| 币种异动 | 加密货币永续合约出现异动 |
| 股票异动 | 美股等 TradFi 合约出现异动 |

每类消息下方会罗列已添加的全部通知渠道，开启对应开关即代表将该类消息投递至该渠道。支持单类消息推向多个渠道，也支持单个渠道接收多类消息。调整后请务必点击 **保存推送路由** 保存生效。

## 每类消息的设置

### 提醒级别

只对 Pushover 生效：

| 级别 | 效果 |
| --- | --- |
| 紧急提醒 | 一直重复提醒，直到你确认或到期 |
| 高优先级 | 提醒一次，可以突破手机的部分静音设置 |
| 普通提醒 | 正常提醒一次 |
| 低优先级 | 不响铃，只显示 |
| 静默提醒 | 不提醒，只留在 Pushover 里 |

展开 **Pushover 声音与重复提醒** 可以设置铃声名称（例如 `siren`、`pushover`）。选了紧急提醒时，还可以设置重复间隔（至少 30 秒）和到期时间（最多 3 小时，不能小于重复间隔）。

<Aside type="tip">
为价格警报与异动通知配置不同提示音，无需查看屏幕即可快速分辨消息类型。
</Aside>

### 每日上限

每个渠道针对每类消息每日支持发送的最大数量，可在 1 到 50 之间自定义，额度于 UTC 零点（北京时间早上 8 点）统一重置。

价格警报另外有一个账户级的每日尝试次数，包含失败重试，详见 [额度与限制](/account/limits/)。

### 免打扰

开启免打扰开关后，可自定义开始与结束时间（默认 23:00 至 07:00）。在该时段内，对应类别的消息将暂停推送；时间按你保存设置时所用设备的本地时区进行计算。开始时间与结束时间不可相同。

## 常见设置示例

**价格警报发手机，异动发 Discord 频道。** 价格警报只打开 Pushover 渠道，币种异动只打开 Discord 渠道。

**夜里只收价格警报。** 给币种异动和股票异动打开免打扰，价格警报不开。
