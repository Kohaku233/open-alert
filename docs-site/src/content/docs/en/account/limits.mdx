---
title: Limits
description: How many alerts each account can create and how many notifications it can receive.
---

These are the limits during the beta. All daily limits reset at 00:00 UTC (8:00 AM Beijing time).

| Item | Limit |
| --- | --- |
| Price alerts | 20, including paused ones |
| Market slots | 8 |
| Notification channels | 10 |
| Asset favorites | 50 |
| Daily price alert attempts | 20, including tests, failures and retries |
| Daily limit per channel, per message type | 1 to 50, set by you, 10 by default |

## Site-wide shared limits

The site also has site-wide limits, such as the total number of active alerts and the total number of notifications per day. All users share these limits. When they are close to full, creating a new alert may fail with the message "The alert, market or user limit has been reached."
